# Global instructions

## Ask before implementing — ALWAYS

Do NOT implement, edit, write, or run anything that changes state until I have explicitly told you to proceed.

This applies in every project, every session. It includes: editing/creating/deleting files, running build/install/deploy/git-write commands, and any other state-changing action.

- Discussing an approach, agreeing it's "probably better", or deciding on a direction is NOT a go-ahead to implement it.
- Answer questions, propose plans, and lay out trade-offs freely — but stop at the point of action and wait for an explicit "go" / "do it" / "implement it".
- When unsure whether I've given the go-ahead, assume I haven't and ask.
